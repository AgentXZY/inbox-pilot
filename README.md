# Inbox Pilot

An open-source AI-powered inbox assistant that transforms hundreds of emails into one intelligent daily briefing — categorized, prioritized, and deadline-aware.

> People don't need another email client — they need an assistant that tells them what actually matters.

## What it does

Inbox Pilot connects to your Gmail inbox, reads recent emails, and uses an LLM to:
- **Categorize** each email (College, Work, Finance, Shopping, Social, Newsletters, Promotions, Security, Other)
- **Rank importance** (HIGH / MEDIUM / LOW) based on urgency and relevance
- **Extract deadlines** mentioned in the email body
- **Summarize** each email in one sentence
- **Surface action items** that actually need a response

Instead of scrolling through hundreds of emails, you get one digest.

## Status

This is an early, working MVP — not production-ready. Tested end-to-end against a real Gmail inbox.
